FARTOVIY — интерактивное демо магазина

Доступ по ссылке и QR
  Адрес сайта: https://fartoviy-classroom-demo.workspace-566219.chatgpt.site
  Экран с QR: https://fartoviy-classroom-demo.workspace-566219.chatgpt.site/share/
  share/qr.png — QR-код для вставки в слайд или показа с экрана.
  share/qr.svg — векторная версия для печати и масштабирования.
  share/url.txt — адрес, записанный в QR-коде.
  QR ведёт на сайт в интернете, а не на localhost.

Запуск
  1. Установите Node.js 18 или новее.
  2. В этой папке выполните: npm start
  3. Откройте http://localhost:3000

Установка зависимостей не требуется. Также можно открыть index.html
двойным кликом, но для доступа к камере лучше использовать localhost.
Для другого порта в PowerShell: $env:PORT=3001; npm start

Что можно попробовать
  - Переключение русского и украинского языка (RU / УКР), выбор сохраняется.
  - Нейтральное демо: цены в условных единицах, без привязки к стране.
  - Главная, каталог, новинки, карточки товаров, избранное и корзина.
  - Поиск по названию, фильтры категорий, сортировка по цене.
  - Выбор размера, добавление в корзину, изменение количества и удаление.
  - Кнопка «Купить сейчас» с переходом к оформлению.
  - Сохранение корзины и избранного в localStorage браузера.
  - Камера с разрешения пользователя или загрузка фото до 15 МБ.
  - После фото — выбор категории и демонстрационная подборка.
  - Оформление тестового заказа с очисткой корзины после подтверждения.
  - Кнопка «Оплатить демо»: подтверждение без банковской карты и списания денег.
  - Адаптивная вёрстка для телефона, планшета и компьютера.

Границы демо
  Товары и цены вымышлены. Оплаты и отправки заказов нет.
  Распознавание изображения не подключено: категория выбирается вручную.
  Фото и данные формы не отправляются на сервер и не сохраняются.
  Браузер запрашивает доступ к камере только после нажатия кнопки.
  При закрытии окна поиска камера отключается.

Структура
  index.html       — оболочка приложения и диалоговые окна
  styles.css       — стили и адаптивная вёрстка
  app.js           — каталог, маршруты, корзина, камера и демозаказ
  i18n.js          — русский и украинский переводы интерфейса
  server.mjs       — локальный сервер без сторонних зависимостей
  assets/          — локальные фотографии и иконка сайта
  share/           — QR-код и отдельный экран для показа ссылки
  scripts/build.mjs — подготовка статической версии в dist/

Проверка синтаксиса: npm run check
Подготовка статической версии: npm run build
Фотографии: Unsplash (images.unsplash.com). Шрифт: Golos Text, Google Fonts.
При недоступности Google Fonts используется системный шрифт.

Первоначальный ориентир из переписки: демо к 28 ноября 2026 года.

настоящий поиск по фото, сервер заказов и оплату.
